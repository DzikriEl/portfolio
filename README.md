# Dzikri Faizziyan — Portfolio

Personal portfolio website of **Dzikri Faizziyan**, working at the intersection of data, research, and insight.

**Live site:** <https://dzikriel.github.io/portfolio/>

## Tech stack

- HTML, CSS, vanilla JavaScript
- Google Fonts
- Hosted on GitHub Pages

## Structure

| File | Section |
|---|---|
| `index.html` | Home — hero, about, skills |
| `experience.html` | Work, internship & organizational experience |
| `projects.html` | Selected projects |
| `speaking.html` | Speaking & moderation |
| `certifications.html` | Licenses & certifications |
| `contact.html` | Contact & personal philosophy |

## Local development

Open `index.html` in a browser, or serve the folder with any static server
(e.g. the "Live Server" extension in VS Code).
